TCG THE RED Mobile PWA

아이폰에서 앱처럼 쓰는 방법
1. 이 폴더 전체를 HTTPS 웹호스팅에 업로드합니다.
   (GitHub Pages / Netlify / Cloudflare Pages 등)
2. 업로드된 주소를 iPhone Safari로 엽니다.
3. Safari 공유 버튼 → '홈 화면에 추가'
4. 이후 홈 화면의 TCG THE RED 아이콘으로 실행합니다.

주의
- 파일 앱에서 index.html을 직접 열면 PWA/자바스크립트 기능이 정상 동작하지 않을 수 있습니다.
- 반드시 HTTPS 웹주소로 열어주세요.
- 한 번 설치 후에는 서비스워커 캐시 덕분에 오프라인에서도 열릴 수 있습니다.
